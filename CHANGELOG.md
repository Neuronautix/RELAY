# Changelog

All notable changes to RELAY will be documented here. RELAY components are versioned independently; this file records repository-level milestones.

## Unreleased

### Added

* Initial six-object repository architecture.
* Draft Core domain and internal term registry.
* Draft RO-Crate package strategy and Core Exchange profile.
* Object templates, governance, contribution process, and automated repository validation.
* MIT licensing, citation metadata, a security policy, a code of conduct, and automated dependency-update configuration.
* Git-enforced LF line endings and integrity metadata for the draft package example.
* Installable `relay` CLI with explainable JSON reports, package-manifest construction and verification, Profile diff/migration analysis, and a composite GitHub Action.
* Named maintainer ownership, issue routing, release and archival procedures,
  and checksum-producing release-artifact automation.

### Changed

* Removed the Package-to-application-Profile back-reference and classified Profile Rules explicitly.
* Strengthened repository validation for malformed descriptors, object contracts, references, and example integrity.
