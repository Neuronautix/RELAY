# Draft minimal RO-Crate

This example illustrates the intended separation among Dataset, DatasetRelease, and ExchangePackage. It is not yet a valid RELAY conformance fixture because the persistent RELAY RO-Crate Profile URI and full package validator are pending.

The example uses RO-Crate 1.3, a DatasetRelease as the root, a distinct conceptual Dataset, a RELAY Core metadata payload, a structured SHA-256 payload manifest, and an explicitly non-conformant draft validation report.
