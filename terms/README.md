# Terms

Terms are the smallest stable semantic units in RELAY. The initial registry is kept in `registry.yaml`; it may later be split into one file per Term without changing identifiers.

A Term defines meaning, not profile requiredness and not a serialization field. Profiles constrain Terms. Mappings relate Terms to external concepts. Rules test their permitted use.

No external ontology layer is normative in the initial release. External mappings will be added only after the internal structure is stable and tested against real data.
