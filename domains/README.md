# Domains

Domains are reusable semantic modules. They own scope and dependencies but do not decide which metadata are mandatory for every exchange. Requiredness belongs to Profiles.

Initial proposed domains:

```text
core
isa
study-design
subjects
biospecimens
housing-cages
environment
protocols-execution
interventions-procedures
assays-acquisition
observations-results
data-assets
analysis-qc
compliance-welfare
```

The presence of a proposal descriptor does not mean the Domain is complete or stable. Each Domain matures independently.
